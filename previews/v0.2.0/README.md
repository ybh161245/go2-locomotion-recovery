# v0.2.0 运动控制与变速研究预览

此目录公开 212 运动候选、249/254 固定变速重放所需的代码与配置，以及截至 2026-11-12 的 253、255 研究快照。文件为预览版，不覆盖根目录的冻结 157 首版；253/255 没有替换已选基线。

## 下载与运行

完整模型、归一化参数、第三方网格、归档轨迹和一个对照视频在 [v0.2.0 Release 附件](https://github.com/ybh161245/go2-locomotion-recovery/releases/tag/v0.2.0) 中；仅下载仓库源码不含运行所需的全部文件。下载 `go2-v0.2.0-preview.zip`，解压后按包内 [START_HERE.md](START_HERE.md) 安装依赖并运行。环境验证为 Windows、CPython 3.13.14 和锁定依赖。
