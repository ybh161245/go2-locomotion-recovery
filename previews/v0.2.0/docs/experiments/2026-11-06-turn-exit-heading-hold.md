# 208　出弯朝向保持的有限对照

单一问题是能否以自身测得的出弯朝向作为参考，减少第207轮在加速直行首秒的偏航。冻结197和原模型。仅在有转速请求切换到0.4 m/s直行时锁存当前偏航角，直行请求改变即清除。完整D路由、无恢复混合且学习支撑未启用时，对D策略同一观测的yaw通道加0.25倍的额外yaw请求。额外请求为0.4乘环绕后的参考角减当前角，限幅±0.06 rad/s，沿用原朝向反馈数值。前3帧仍处原路由混合时跳过。原指令、滤波、转向反馈和原生关节目标映射保持。运行时只读取自身偏航、请求及现有路由状态。

第207轮四条原记录作配对，新候选在同两方向零力/30 N短推各跑一次，最多4新仿真，0训练/拟合。原完整28秒、8度、2秒/连续25步恢复、4条出弯稳定和196项动作质量门槛照用。新开发指标为出弯后一秒的绝对朝向变化，两个受推都须下降，受推最差值至少下降0.5度。四条的4秒末绝对朝向变化最大值不得上升。新增数字为本轮设计选择，207原成绩保持。连续退步逐条保留。

运行前冻结配置/输入SHA。核对与207的初态/物理/首个真实变化之前的8数组，同版zero/push施力前8数组，以及原命令、实际关节目标和世界力。每格一次。未达开发指标即拒绝本规则，不在本轮扫描增益；达标也仅为已打开开发对照，先保护正常任务再考虑新范围。
