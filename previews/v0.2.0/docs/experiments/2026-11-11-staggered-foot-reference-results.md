# 255 错相足序预检与关节命令边界

以249稳态机身高度中位数296.756 mm构造水平机身参考。两套参考均为0.8 m/s、1.75 Hz、60%支撑占比、65 mm摆动目标，单足计划支撑期间相对机身后移274.286 mm。错相方案的后脚相位提前0.10周期，约57.14 ms。两套各200帧，涵盖7个参考周期。动力学步、训练和模型拟合均为0。

参考支撑时序符合预期，几何预检失败。每套800个足端采样中，424个超过2 mm，全部超差采样的逆解至少有一个关节触及命令边界。错相方案最差样本的RR大腿目标达1.15 rad上限，足端比参考低39.44 mm，前后及横向也存在偏差。两套参考保留了相同的逐足轨迹，仅改变相位，因此各腿在一个完整相位网格内的误差分布相同。小于旧预算的目标步变属于静态命令结果，真实动作质量仍待实测。

这次测量针对固定机身高度、足端曲线和有界数值逆解。最大误差出现在摆动，支撑段也有超差，部分重建足底低于参考平面。该结果说明这套参考在当前求解和命令范围下无法直接使用。参考支撑数量来自相位标记，动态接触、承重和速度波动尚无新测量。

下一项可以从249已经实际下发的关节目标中构造周期参考，在关节空间保持原命令界限，再单独验证后腿错相对真实承重、抬脚和速度的影响。该方案需要同步与错相配对，事前固定相位、幅度、进入和退出方式及仿真预算。255未获得训练示范，G3状态及249原始评分继续按原记录使用。
