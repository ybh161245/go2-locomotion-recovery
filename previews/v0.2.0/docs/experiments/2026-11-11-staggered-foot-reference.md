# 255 错开前后脚落脚的运动学预检

单一问题是，能否在原关节命令范围内表达一套保持左右半周期对称、将前后脚参考落脚错开的0.8 m/s步态。252显示速度波动与步态周期相关，且大部分偏航尖峰与四脚承重同现。错开足序改变参考支撑重叠，实测速度和接触响应留待动力学验证。

固定两套参考。对角同步方案采用FL、FR、RL、RR相位偏移`[0,.5,.5,0]`，错开方案仅将两后脚相位各提前0.10周期，约57.1毫秒。两方案沿用1.75 Hz、60%参考支撑比例及65 mm参考摆动高度。以249的8–12秒机身高度中位数放置水平机身，水平中心取原nominal构型足端坐标。固定步长为指令速度除以步频。参考支撑期间，足端相对机身以−0.8 m/s向后扫。摆动采用五次平滑进度叠加到支撑直线延拓，保证前后端速度与支撑相接。足高采用原sin²抬脚曲线。四足以足底高度0作为参考地面。

固定200个50 Hz参考采样，覆盖7周期。每足在原nominal±0.35 rad与原生关节范围的交集内，以固定阻尼Jacobian数值逆解将参考足端转成目标。保存所有帧，不筛时刻。事前门槛为逐足三维目标误差最大≤2 mm，所有关节在原范围内，50 Hz关节目标向量最大步变与P95均≤249原值的110%，错开方案参考支撑每帧≥2脚且四脚同时参考支撑的帧数低于同步方案。参考足序与真实承重各有独立口径。

预算为两套固定参考各200帧，0动力学步、0训练、0模型拟合。保存输入和源码哈希、轨迹数组、逐足误差和对照图。若几何不过，保留误差与边界，不放宽关节范围或调参后回填。若通过，仅取得开展新动力学小试的依据，原249的25步稳定门槛及质量预算继续使用，另立预算后才开动力学。
